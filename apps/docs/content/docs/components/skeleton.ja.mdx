## 使い方

```tsx
import { Skeleton } from "@murasakijs/ui";
```

```tsx
<Skeleton className="h-4 w-[250px]" />
```

## API リファレンス

### Props

`Skeleton` は固定サイズを持たない、パルスアニメーション付きの `<div>` をレンダリングします — `className`(`h-*`・`w-*`・`rounded-*`)で、置き換えたいコンテンツに合わせて円形・線・ブロックの形に整えてください。
