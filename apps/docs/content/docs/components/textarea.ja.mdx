## 使い方

```tsx
import { Textarea } from "@murasakijs/ui";
```

```tsx
<Textarea placeholder="Type your message here." />
```

## API リファレンス

### Props

`Textarea` はネイティブの `<textarea>` 要素をスタイリングした薄いラッパーです —
`placeholder`・`rows`・`disabled`・`value`・`onChange` など、すべての属性はそのまま
渡されます。
