## 使い方

```tsx
import { Progress } from "@murasakijs/ui";
```

```tsx
<Progress value={60} />
```

## API リファレンス

### Props

| Prop | 型 | デフォルト |
| --- | --- | --- |
| `value` | `number \| null` | — |

`Progress` は React Aria のプログレスバーセマンティクスを使用し、`value`(0〜100)
に応じてインジケーターを水平方向に移動させます。
