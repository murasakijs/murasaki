## 使い方

```tsx
import { Badge } from "@murasakijs/ui";
```

```tsx
<Badge>Badge</Badge>
```

## API リファレンス

### Props

| Prop | 型 | デフォルト |
| --- | --- | --- |
| `variant` | `"default"` \| `"secondary"` \| `"outline"` \| `"destructive"` | `"default"` |

`Badge` は `<div>` をレンダリングし、それ以外の props（`className`・`onClick` など）はすべてそのまま渡されます。
