[`@murasakijs/ui`](https://www.npmjs.com/package/@murasakijs/ui) is the
component library the scaffold installs by default — built on Radix
primitives, styled with Tailwind CSS and `class-variance-authority`, using
the same `cn()` conventions shadcn/ui users already know. These pages document
the real exported APIs; previews shown in a page render the published component.

See the [Styling](/docs/guides/styling) guide for how the library is wired
into a scaffolded app (stylesheet import, Tailwind preset, dark mode).
