## 使い方

```tsx
import { Label } from "@murasakijs/ui";
```

```tsx
<Label htmlFor="email">Email</Label>
```

## API リファレンス

### Props

`Label` は Radix UI の [`Label.Root`](https://www.radix-ui.com/primitives/docs/components/label)
をレンダリングし、ネイティブの `<label>` 属性をすべてそのまま渡します。`htmlFor` と
対象コントロールの `id` を一致させておくと、ラベルをクリックしたときにそのコントロー
ルにフォーカスが移ります。
