## Usage

```tsx
import { Popover, PopoverContent, PopoverTrigger } from "@murasakijs/ui";
```

```tsx
<Popover>
  <PopoverTrigger>Open</PopoverTrigger>
  <PopoverContent>Place content for the popover here.</PopoverContent>
</Popover>
```

## API Reference

### Subcomponents

| Component | Description |
| --- | --- |
| `Popover` | The root primitive. Accepts `open`, `defaultOpen`, `onOpenChange`, `modal`. |
| `PopoverTrigger` | The element that opens the popover. Supports `asChild`. |
| `PopoverAnchor` | An optional element to anchor positioning to, instead of the trigger. |
| `PopoverContent` | The popup panel. Accepts `align` (default `"center"`) and `sideOffset` (default `4`). |

Focus handling, dismissal, and collision-aware positioning are provided by
React Aria Components.
