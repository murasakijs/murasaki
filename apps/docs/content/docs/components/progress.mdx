## Usage

```tsx
import { Progress } from "@murasakijs/ui";
```

```tsx
<Progress value={60} />
```

## API Reference

### Props

| Prop | Type | Default |
| --- | --- | --- |
| `value` | `number \| null` | — |

`Progress` renders a Radix UI [`Progress.Root`](https://www.radix-ui.com/primitives/docs/components/progress)
whose indicator is translated horizontally based on `value` (0–100).
