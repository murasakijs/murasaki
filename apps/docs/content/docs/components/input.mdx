## Usage

```tsx
import { Input } from "@murasakijs/ui";
```

```tsx
<Input type="email" placeholder="Email" />
```

## API Reference

### Props

| Prop | Type | Default |
| --- | --- | --- |
| `type` | `string` | `"text"` |

`Input` is a thin styled wrapper around the native `<input>` element — every
other attribute (`placeholder`, `disabled`, `value`, `onChange`, `required`,
...) is forwarded straight through.
