## 使い方

```tsx
import { Input } from "@murasakijs/ui";
```

```tsx
<Input type="email" placeholder="Email" />
```

## API リファレンス

### Props

| Prop | 型 | デフォルト |
| --- | --- | --- |
| `type` | `string` | `"text"` |

`Input` はネイティブの `<input>` 要素をスタイリングした薄いラッパーです — `placeholder`・`disabled`・`value`・`onChange`・`required` など、それ以外の属性はすべてそのまま渡されます。
