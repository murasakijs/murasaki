---
title: Menubar
description: キーボードで移動できる、アプリ内の常設メニューを表示します。
---

<ComponentPlayground name="menubar" />

## 使い方

```tsx
import { Menubar, MenubarContent, MenubarItem, MenubarMenu, MenubarShortcut, MenubarTrigger } from '@murasakijs/ui'

<Menubar>
  <MenubarMenu>
    <MenubarTrigger>ファイル</MenubarTrigger>
    <MenubarContent>
      <MenubarItem>新規ウィンドウ <MenubarShortcut>⌘N</MenubarShortcut></MenubarItem>
      <MenubarItem>開く… <MenubarShortcut>⌘O</MenubarShortcut></MenubarItem>
    </MenubarContent>
  </MenubarMenu>
</Menubar>
```

アプリ内のどの画面でも利用するコマンドに向いています。これはレンダラー用のコンポーネントです。OS のメニューバーに表示するコマンドには、Murasaki のネイティブメニュー設定を使ってください。

## エクスポート

`MenubarCheckboxItem`, `MenubarRadioGroup`, `MenubarRadioItem`, `MenubarGroup`,
`MenubarLabel`, `MenubarSeparator`, `MenubarShortcut`, `MenubarSub`,
