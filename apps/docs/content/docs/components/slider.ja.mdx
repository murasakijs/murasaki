title: Slider

<ComponentPlayground name="slider" />

## 使い方

```tsx
import { Slider } from '@murasakijs/ui'

<Slider aria-label="音量" defaultValue={[40]} max={100} step={1} />
```

`Slider` は、`value`・`defaultValue`・`min`・`max`・`step`・`orientation`・`onValueChange` など、React Aria の Slider の props を Murasaki の配列値互換 API 経由で受け取ります。値の数だけつまみが表示されます。表示されているラベルか `aria-label` を使って、必ずアクセシブルな名前を指定してください。つまみ同士の最小間隔が必要な範囲選択には `minStepsBetweenThumbs` を使います。
