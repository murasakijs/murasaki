<ComponentPlayground name="slider" />

## 使い方

```tsx
import { Slider } from '@murasakijs/ui'

<Slider aria-label="音量" defaultValue={[40]} max={100} step={1} />
```

`value`, `defaultValue`, `min`, `max`, `step`, `orientation`,
`onValueChange` など、React Aria Slider を配列値 API に合わせた props を受け取ります。
値の数だけつまみが表示されます。表示ラベルか `aria-label` で、必ず操作の
名前を伝えてください。範囲選択で最小間隔が必要なら
`minStepsBetweenThumbs` を指定します。

## エクスポート
