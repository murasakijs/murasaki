## 使い方

```tsx
import { Separator } from "@murasakijs/ui";
```

```tsx
<Separator />
```

## API リファレンス

### Props

| Prop | 型 | デフォルト |
| --- | --- | --- |
| `orientation` | `"horizontal"` \| `"vertical"` | `"horizontal"` |
| `decorative` | `boolean` | `true` |

`Separator` は React Aria のセパレーターセマンティクスを使用します。`decorative` が `true` の場合、支援技術からは隠されます（純粋に見た目のための区切り線として扱われます）。区切りに意味がある場合は `false` を指定してください。
