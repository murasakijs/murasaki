[`@murasakijs/ui`](https://www.npmjs.com/package/@murasakijs/ui) は、スキャフォー
ルドがデフォルトでインストールするコンポーネントライブラリです — Radix プリミティブ
をベースに、Tailwind CSS と `class-variance-authority` でスタイリングされており、
shadcn/ui ユーザーにはおなじみの `cn()` の作法をそのまま使っています。このページに
掲載されている各コンポーネントは、実際に公開されているものそのものをライブでレンダリ
ングしています。

コンポーネントライブラリがスキャフォールドされたアプリにどう組み込まれるか(スタイル
シートの読み込み、Tailwind プリセット、ダークモード)については、[Styling](/docs/guides/styling)
ガイドを参照してください。
