[`@murasakijs/ui`](https://www.npmjs.com/package/@murasakijs/ui) は、スキャフォー
ルドがデフォルトでインストールするコンポーネントライブラリです — React Aria
Components をベースに、Tailwind CSS と `class-variance-authority` でスタイリングされており、
shadcn/ui ユーザーにはおなじみの `cn()` の作法をそのまま使っています。各ページは実際に
公開されている API を説明しており、プレビューがあるページでは公開版のコンポーネントを
そのまま描画しています。

コンポーネントライブラリがスキャフォールドされたアプリにどう組み込まれるか(スタイル
シートの読み込み、Tailwind プリセット、ダークモード)については、[Styling](/docs/guides/styling)
ガイドを参照してください。
