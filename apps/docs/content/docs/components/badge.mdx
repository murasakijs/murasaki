## Usage

```tsx
import { Badge } from "@murasakijs/ui";
```

```tsx
<Badge>Badge</Badge>
```

## API Reference

### Props

| Prop | Type | Default |
| --- | --- | --- |
| `variant` | `"default"` \| `"secondary"` \| `"outline"` \| `"destructive"` | `"default"` |

`Badge` renders a `<div>`; all other props (`className`, `onClick`, ...) are
forwarded to it.
