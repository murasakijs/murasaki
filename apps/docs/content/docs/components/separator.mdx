## Usage

```tsx
import { Separator } from "@murasakijs/ui";
```

```tsx
<Separator />
```

## API Reference

### Props

| Prop | Type | Default |
| --- | --- | --- |
| `orientation` | `"horizontal"` \| `"vertical"` | `"horizontal"` |
| `decorative` | `boolean` | `true` |

`Separator` renders a Radix UI [`Separator.Root`](https://www.radix-ui.com/primitives/docs/components/separator).
When `decorative` is `true` it's hidden from assistive technology (purely
visual); set it to `false` if the separator is semantically meaningful.
