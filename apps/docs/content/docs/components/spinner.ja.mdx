---
title: Spinner
description: 処理が進行中であることを示します。
---

## 使い方

```tsx
import { Button, Spinner } from '@murasakijs/ui'

<Button disabled>
  <Spinner aria-label="保存中" />
  保存中…
</Button>
```

`Spinner` は `role="status"` を持つ SVG を表示します。隣に処理内容を説明するテキストがない
場合は、既定の「Loading」ではなく、処理に合った `aria-label` を指定してください。継続的な
アニメーションが必須でない場合は、アプリのスタイルで `prefers-reduced-motion` に対応します。
