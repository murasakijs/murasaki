## Usage

```tsx
import { Checkbox } from "@murasakijs/ui";
```

```tsx
<Checkbox id="terms" />
```

## API Reference

### Props

| Prop | Type | Default |
| --- | --- | --- |
| `checked` | `boolean \| "indeterminate"` | — |
| `defaultChecked` | `boolean \| "indeterminate"` | — |
| `onCheckedChange` | `(checked: boolean \| "indeterminate") => void` | — |
| `disabled` | `boolean` | `false` |
| `required` | `boolean` | `false` |
| `name` | `string` | — |
| `value` | `string` | `"on"` |

`Checkbox` renders a Radix UI [`Checkbox.Root`](https://www.radix-ui.com/primitives/docs/components/checkbox);
all other props are forwarded to it.
