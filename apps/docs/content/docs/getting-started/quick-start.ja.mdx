title: クイックスタート
description: Murasaki アプリをスキャフォールドし、HMR 付きで実行し、配布物をビルドします。
---

## 前提条件

- **Node.js 22.12 以上**（EOLのNode 20はサポート対象外）
- `murasaki dev` は **macOS、Windows、Linux** で動作します。macOS の `.app` / `.dmg`
  は macOS 上でビルドする必要があります。ポータブルな Windows フォルダー / `.zip` は
  どのホストからでもクロスビルドできます。Linux 向けアプリパッケージはロードマップにあ
  ります。

## スキャフォールド

```bash
pnpm create murasaki@latest my-app
cd my-app
```

これにより、Next.js ライクなレイアウト、ネイティブウィンドウ、そして動作するコンテキス
トメニューを備えた React 19 + Vite + Tailwind アプリが作成されます。`index.html` やエン
トリファイルを管理する必要はありません(アプリシェルは Murasaki が管理します)。

## 開発

```bash
pnpm dev
```

Vite の開発サーバーの上にネイティブウィンドウが開きます — **React Fast Refresh と HMR
は通常どおり動作します**。`src/app/page.tsx` を編集すると、ウィンドウが即座に更新され
ます。

アプリ内のどこでも右クリックするとネイティブメニューが表示されます。カードを右クリック
すると、そのカード専用のスコープ付きメニューが表示されます — どちらも本物の `NSMenu`
であり、HTML のポップアップではありません。

## 配布物をビルドする

```bash
pnpm bundle
pnpm installer
```

バンドルにはポータブルな Node ランタイムとネイティブランチャーが同梱されるため、ビルド
したマシン以外でも動作します。macOS では最初の2コマンドで `.app` と `.dmg` を生成しま
す。Windows ターゲットを指定すると、どのホストからでもポータブルな Windows フォルダー
と `.zip` を作成できます。

```bash
pnpm bundle --arch x64            # ターゲットアーキテクチャを指定
pnpm bundle --target win32-x64    # ポータブルな Windows フォルダー + .zip
```

`pnpm installer --target win32-x64` は、`makensis` があれば NSIS `.exe`、Windows 上で WiX
v4 があれば MSI `.msi` も生成します。どちらの任意ツールもない場合、Windows インストー
ラーは生成されませんが、ポータブルな `.zip` は利用できます。ツールのセットアップと全
ターゲットは[配布](/docs/building/distribution)を参照してください。

<Callout type="warn">
  macOS では、署名されていないビルドは他のマシンで Gatekeeper をトリガーします(受け
  取った側は初回のみ右クリック→**開く**が必要です)。警告なしで署名・公証済みのアプリ
  を配布する方法は、[Distribution →
  Signing](/docs/building/distribution#signing--notarization) を参照してください。
</Callout>
