Murasaki はまだ 1.0 に達していません。現在利用できる機能、OS による重要な差が残る機能、まだ設計段階の機能があります。このページは、リポジトリ内の正式な機能マニフェストである[`packages/murasaki/capabilities.json`](https://github.com/murasakijs/murasaki/blob/main/packages/murasaki/capabilities.json)から生成しています。

<Callout type="warn">
  **「計画中」は「利用可能」という意味ではありません。** 依存パッケージ、Rust のモジュール、型、ロードマップが存在するだけでは、提供済みの機能とはみなしません。Murasaki が正式な利用方法を公開し、その制限をここへ記録した時点で対応扱いにします。
</Callout>

## 状態の定義

- **安定** — 現在のリリース系列で互換性を維持する公開 API です。
- **実験的** — 実装と検証はありますが、1.0 までに API や通信形式が変わる可能性があります。
- **部分対応** — 現在利用できますが、表に記載した重要な API または OS ごとの差があります。
- **計画中** — 正式に利用できる実装はありません。

機能の成熟度と OS 対応は別々に表示します。**開発のみ**は、その OS で開発用ランタイムを利用できても、本番用パッケージの動作までは保証しないことを示します。**未対応**は、その OS に実装がないか、機能自体が適用されないことを示します。

## 検証根拠の読み方

各行の**API と検証根拠**を開くと、正式な公開シンボルと、根拠となる自動テストまたはワークフローを確認できます。ビルドのワークフローが示すのは、その OS でコンパイルできることまでです。未公開のネイティブヘルパーを正式なフレームワーク API とみなす根拠にはなりません。

実装とマニフェストに差がある場合は、より低い対応状況を安全側の前提として扱い、[不一致を報告してください](https://github.com/murasakijs/murasaki/issues)。
